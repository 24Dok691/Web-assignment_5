## Description
Multi-page website with JavaScript tasks. Navigation bar links to all parts.

| Page | Tasks | JS file |
| --- | --- | --- |
| `index.html` | Task 0 (first script), Task 1 (variables & operators) | `part1.js` |
| `dom.html` | Task 2 (content), Task 3 (styles), Task 4 (add/remove items) | `dom.js` |
| `events.html` | Task 5 (mouse), Task 6 (keyboard), Task 7 (calculator) | `events.js` |
| `todo.html` | Task 8 (To-Do app) | `todo.js` |

Styles: `styles.css` + Bootstrap 5 (CDN).

## How to run
1. Clone the repository or download the files.
2. Open `index.html` in a browser (or use Live Server).
3. Open the console (F12) to see the output of Task 0 and Task 1.
